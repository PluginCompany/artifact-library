This is a second HTML file in the same directory. Its styles, diagram, and navigation all use relative paths.

1

Create the directory.

Put your entry point and supporting files together. Keep links relative so the directory can move as a unit.

report/
  index.html
  walkthrough.html
  notes/field-guide.html
  assets/style.css
  assets/app.js
  assets/activity.json
  assets/motion.mp4
2

Publish a complete snapshot.

The CLI streams an archive to the server. The server validates it, hashes the files, and commits an immutable version.

artifact publish ./report \
  --slug fieldnotes \
  --title "Fieldnotes" --json
3

Share the stable link.

The stable URL redirects to the latest snapshot. Browser-relative links then stay inside that snapshot, even after another version is published.

/artifacts/fieldnotes/
  → /artifacts/fieldnotes/_versions/1/
4

Update with context.

Check the revision, change the local files, and publish the whole directory again. An old open tab offers to open the latest version.

artifact check ./report --json
artifact update fieldnotes ./report \
  --message "Added a field guide" --json

One useful constraint

Each update replaces the entire file tree. A file you leave out is removed from the latest version, but preserved in its older snapshots.
