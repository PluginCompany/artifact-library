What happens to your files

A snapshot,
not a rebuild.

The CLI sends the directory. The server stores a complete version and serves the original assets. There’s no build step hiding behind the link.

Read the walkthrough
  • Relative links keep multiple pages connected.
  • Old versions retain their original scripts and images.
  • Downloads contain original, unmodified files.
