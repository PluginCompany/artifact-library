Start a new artifact

Three steps from a reference to your own published page.

  1. Download the closest reference

    Every artifact downloads with its kit, fonts and data files — it works offline.

    artifact download ref-ops-report --out ./my-report

  2. Change the content, not the plumbing

    Each index.html opens with an Editing guide comment. Numbers and lists live in data.js; styles come from kit/.

  3. Publish under a new slug

    Pick a title and a one-sentence description; share the latest URL.

    artifact publish ./my-report --slug q4-report \
  --title "Q4 operations report" \
  --description "Throughput, quality and staffing for Q4." --json
Working in the repo?The sources live in examples/reference/. ./publish.sh <dir> bundles the shared kit and publishes or updates in one step. New servers seed this whole collection on first start.
Reading feedbackPages that save write answers, comments and verdicts beside the artifact. Read them with artifact feedback <slug>; reply with artifact data append.
House rules
  • Colours come from kit tokens, so dark mode and print work automatically.
  • Status always carries a word, never colour alone.
  • Every chart has a table view and a one-line takeaway.
  • Label example content as example content.
  • Check it at 375 px wide before you share it.
