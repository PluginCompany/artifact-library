Style guide

Every token and component the reference artifacts are built from. Examples are live — toggle the theme in the top bar to check both modes — and each one shows the markup to copy.

Colour tokens

Use tokens, never raw hex. Dark mode swaps the token values, so components need no dark-specific CSS. Values below are read live from the stylesheet.

Theme tokens

The kit's signature details, as tokens so a theme in kit/themes/ can restyle every page. Use them in page CSS too. Readers switch between Bold and Clean with the style button next to the light/dark toggle; link kit/themes/clean/clean.css after every other stylesheet to make Clean a page's default.

Typography

Bricolage Grotesque for headings, Noto Sans for reading, JetBrains Mono for labels and numbers that align. Fonts are bundled in kit/fonts.

Charts

SVG charts with hover tooltips, a legend for two or more series, and a table view. Series colours follow slots 1–5 in a fixed order, which keeps them distinguishable for colour-blind readers. One axis per chart.

Kit.chart.line(el, {
  labels: ["W27", "W28", "W29"],
  series: [{ name: "Bench A", values: [112, 115, 116] }, { name: "Bench B", values: [107, 109, 110] }],
  format: "int"          // int | dec1 | pct | compact | hours | (v) => string
});
Kit.chart.column(el, { labels, series, stacked: true });
Kit.chart.bar(el, { labels, series: [{ name: "Cases", values }] });
Kit.chart.donut(el, { labels, values, format: "pct", center: { value: "62%", label: "on the stand" } });

Saving & comments

Load kit/kit-data.js after kit/kit.js. On the artifact server, what readers save goes into documents beside the artifact, and agents read it with artifact feedback <slug>. Opened from disk, it falls back to this browser and the status says so. Try it: this thread is live.

Comment thread

<span data-save-status></span>      <!-- save state in the top bar -->
<div id="thread"></div>
<script>
document.addEventListener("kit:ready", () =>
  Kit.comments(document.getElementById("thread"), { key: "finding-F2", title: "Discussion" }));
</script>
await Kit.data.set("answer.toolbar", { questionId: "toolbar", choice: "collapsed", choiceLabel: "Start collapsed", note: "" });
const doc = await Kit.data.get("answer.toolbar");      // { key, value, revision, author, updatedAt }
const stop = Kit.data.watch("state.", docs => render(docs));   // live updates
